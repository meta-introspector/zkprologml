# zkPrologML Dashboard

Live auto-updating dashboard for zkProlog execution with Monster Group visualization.

## Features

- 🌐 Real-time updates (2s interval)
- 🎨 Matrix rain cyberpunk aesthetic  
- 🔢 71 interactive Monster Group shards
- 📊 Live statistics and terminal logs
- 🧠 Tau-Prolog browser queries
- 📈 METIS graph partitioning visualization

## Tech Stack

- Pure HTML/CSS/JavaScript (no build step)
- Tau-Prolog (browser Prolog)
- Canvas API (Matrix effect)
- No backend required
