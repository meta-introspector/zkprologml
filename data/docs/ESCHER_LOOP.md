## The Encoding

Each layer encodes the previous layer as emoji:
- **Prolog → Emoji**: Each byte becomes an emoji (U+1F300 + byte)
- **GPU → Emoji**: Shader code embedded as emoji comments
- **WASM → Emoji**: Module data section contains emoji string
- **Lua → Emoji**: RUNES constant contains entire chain

## The Shards

The complete system splits into **33 runestone shards**:
- Each shard: ~100 emoji characters
- Paste each as `StringValue` in Roblox `ReplicatedStorage`
- Name them: `Shard1`, `Shard2`, ..., `Shard33`

## Reassembly in Roblox

```lua
-- Collect all shards
local shards = {}
for i = 1, 33 do
    local shard = game.ReplicatedStorage:FindFirstChild("Shard" .. i)
    if shard then
        table.insert(shards, shard.Value)
    end
end

-- Reassemble
local complete_runes = table.concat(shards, "")

-- Decode and execute
decode_and_execute(complete_runes)
```
