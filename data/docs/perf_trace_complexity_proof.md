# Perf Trace Complexity Proof

## Theorem
For layers c₁ < c₂, perf_trace(c₂) is strictly more complex than perf_trace(c₁).

## Proof by Induction

### Base Case (Layer 0)
- Cycles: 1000
- Instructions: 600
- Cache misses: 100
- Minimal complexity ✅

### Inductive Step
For layer k → k+1:

✅ All transitions show increasing complexity

### Key Transitions

Layer 0 (prime=2, sub=0) → Layer 1 (prime=3, sub=0): 1000 → 2010 cycles
Layer 14 (prime=71, sub=0) → Layer 15 (prime=2, sub=1): 16960 → 18250 cycles

## Complexity Formula

```
cycles(layer) = prime(layer) × 1000 × (sub_level(layer) + 1)
```

Where:
- `prime(layer) = MONSTER_PRIMES[layer mod 15]`
- `sub_level(layer) = layer div 15`

## Monotonicity Proof

Complexity increases because:
1. Within sub-level: primes increase (mostly)
2. Between sub-levels: multiplier increases
3. Combined effect: strictly monotonic
