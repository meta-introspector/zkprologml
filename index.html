What is zkPrologML?

A collection of self-executing mathematical proofs combining Prolog, Lean4, WASM, and zero-knowledge cryptography.

📝 Prolog Proofs

200+ executable logic programs proving mathematical theorems including Monster group properties, Bott periodicity, and lattice theory.

🔷 WASM Modules

15 self-contained WebAssembly modules with embedded zero-knowledge proofs, executable in any browser.

✓ Lean4 Proofs

50+ formally verified proofs type-checked by Lean4, ensuring mathematical correctness.

📊 Reference Data

227 parquet files (1GB) including LMFDB shards, Lean indexes, and Stack Exchange content.

Quick Start

# Download from archive.org
wget https://archive.org/download/zkprologml-20260130-055017/zkprologml-archive-bundle.tar.gz

# Extract
tar -xzf zkprologml-archive-bundle.tar.gz
cd zkprologml-archive-bundle

# Run all proofs
./run_proofs.sh

Use with Python

from datasets import load_dataset

# Load dataset
ds = load_dataset("introspector/zkprologml")

# Access proofs
for proof in ds:
    print(proof["name"])
