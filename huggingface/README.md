# zkPrologML - LLM.txt for NotebookLM

Zero-Knowledge Prolog Meta-Language documentation generator.

## Features

- Generate llm.txt from zkPrologML repo
- Chunk into 8KB pieces for NotebookLM
- REST API for chunk access
- WASM plugin for zos-server

## Usage

Visit the Space to download llm.txt chunks for NotebookLM.

## Dataset

Chunks stored at: https://huggingface.co/datasets/introspector/llm.txt
